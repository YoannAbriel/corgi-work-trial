# Brand sources

`corgi-logo-full.jpg` (the wordmark with the corgi, 800 x 242) and `corgi-mark.jpg` (the round mark, 1785 x 1785) are the two files Corgi supplied, copied here byte for byte so the repository carries its own originals instead of pointing at somebody's downloads folder. Both are flat orange on flat white; the orange measured on both is `#ff5c00`, which is `--orange` in `app/globals.css` and `PDF_COLOR.accent` in `lib/documents/pdf-theme.ts`. Nothing in the application reads these two files: `npm run brand:assets` (`scripts/brand-assets.mjs`, which uses `sharp`) derives the three PNGs the application actually draws, `public/brand/corgi-mark.png` (512 px), `public/brand/corgi-logo.png` (1200 px wide) and `public/brand/corgi-mark-mask.png` (the mark as a black shape, used as a CSS mask so the sidebar can paint it any colour). The derived files turn the white into transparency by using each pixel's distance to white as its alpha and repainting the colour channels a flat `#ff5c00`, so anti-aliased edges stay soft instead of picking up a pale halo; the script explains the arithmetic in full. The outputs are committed, so no build step depends on this script.
